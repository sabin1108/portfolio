### 공통 폼의 식별값 충돌로 경로 입력이 잘못 연결되는 문제

목적지 선택 화면에는 **기존 폴더를 찾아가기 위한 경로 입력창**과 **새 파일·폴더의 이름을 입력하는 생성 폼**이 있었습니다. 두 폼을 배치하는 상위 화면에서 현재 폴더 경로만 React key로 지정해, 역할이 다른 두 폼에 같은 값이 들어갔습니다. 기존 경로값 앞에 **경로 입력용·새 항목 생성용이라는 역할을 추가**해 서로 다른 key를 지정했습니다.

### 설정을 반복해서 열 때 같은 정보를 다시 기다리는 문제

자주 바뀌지 않는 설정 표시 정보는 **Next.js Data Cache**로 로그인 후 설정에 표시할 정보를 미리 준비했습니다. 현재 인증과 작업 권한은 매번 확인했습니다. 준비시간의 중앙값은 **1.541초 → 0.675초, 약 56.2% 감소**했습니다.

*로컬 production · 반복 설정 진입 36표본 · 초기 준비 비용 별도*

### 길게 누른 뒤 목록이 바뀌어 다른 파일이 열리는 문제

파일을 길게 누르면 선택 모드로 바뀌면서 목록이 밀렸고, 손을 떼는 순간 다른 파일이 열리는 문제가 발생했습니다. 이를 해결하기 위해 **선택 모드로 전환된 직후 발생하는 클릭을 한 번 차단**하고, 선택 표시가 나타나도 목록이 밀리지 않도록 행 높이를 유지했습니다.
