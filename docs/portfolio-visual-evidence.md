# 포트폴리오 시각 자료와 색상 수정

2026-11-18. 기존 원고 문장과 지표는 유지한다. 웹과 PDF를 함께 수정하며, 이력서는 기존 구조에 사용자 지정 모아 저장소·데모 링크를 추가한다. 모바일은 범위 밖이다.

## 수정과 검증 순서

1. 현재 원고와 생성 문서를 기준으로 본문 보존 검사를 유지한다. 기존 휠·읽기 경계·목차·확대·경로 검사에 그림의 존재, 배치, 텍스트 넘침, 대비, 생략 표시를 추가한다.
2. 각 사례의 기록을 전후 비교·타임라인·분기·구조·성과 카드·포인터 흐름으로 그린다. 수치만 있는 검증은 박스형 카드로 보여주고, 기존 검증 문장 안의 수치와 문구를 그대로 유지한다. 실제 화면을 촬영한 것처럼 보이는 가짜 전후 이미지는 만들지 않는다.
3. 기술 선택·인증/단계·컴포넌트/캐시 페이지에는 본문 아래 처리 관계를 그려 큰 창의 아래 공간을 활용한다. 글자 크기·행간·문단 폭과 높이가 다른 데스크톱 창을 함께 확인한다.
4. 배경은 따뜻한 회백색, 본문은 짙은 회녹색으로 바꾸고 아키텍처·파일 구조·뷰어도 같은 계열로 맞춘다. 흰 글자의 강한 대비를 줄이되 읽기 대비는 검증한다.
5. 파일 구조의 features/local-folders/components/ui 가지에 실제 생략된 항목을 뜻하는 `…`를 넣는다.
6. 원문 보존, PDF 글자·경계, 그림별 배치, 데스크톱 브라우저와 휠 회귀 검사를 통과한 뒤 배포한다.

## 프로젝트 링크

사용자가 지정한 `sabin1108/file_moa` 공개 저장소와 데모 접근 URL을 profile.json 한 곳에서 관리한다. 포트폴리오 상단·표지 및 이력서 프로젝트 항목에 표시하고 PDF URI도 확인한다. 데모는 소개 화면→체험 시작→샘플 작업 공간 진입까지 확인했다. 질문 전송이나 AI 실행은 검토 범위에 넣지 않는다.

## 최종 검증

- 기존 원문 비교, 링크, 수치 카드와 4개 데스크톱 크기의 그림 배치 검사 7개 통과. 총 40개 페이지 뷰를 확인했다.
- 데스크톱 회귀 검사 29개 통과. 휠·관성·긴 페이지 읽기 경계·목차·키보드·이력서 탭·확대·이전 경로 차단·다운로드를 포함한다.
- 실제 PDF 29쪽에서 원문 누락과 글자 수 감소가 없고, 주 본문 13.5pt와 용지 경계를 확인했다. 각 PDF의 GitHub·데모 URI 주석도 확인했다.
- production build, TypeScript strict 검사, 휠 단위 검사 통과. 모바일과 데모 AI 응답은 확인하지 않았다.
